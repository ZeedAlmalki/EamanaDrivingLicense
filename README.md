# DVLD System - نظام إدارة رخص القيادة

مشروع برمجي مبسط تم تطويره خلال فترة التدريب العملي في **أمانة المنطقة الشرقية**.

## 🏗️ المعمارية والتقنيات المستخدمة
* **Backend:** .NET 8 Web API (C#) مبني وفق معمارية الطبقات الثلاث (**Three-Tier Architecture**).
* **Database & DAL:** SQL Server مع استخدام **ADO.NET** للاتصال وإدارة قواعد البيانات بكفاءة.
* **Frontend:** HTML5, CSS3, و JavaScript لتوفير واجهة تفاعلية متكاملة مع خدمات الـ API.

## 💡 أبرز المميزات والخصائص
* **فصل الطبقات (Separation of Concerns):** هيكلية نظيفة تفصل طبقة العرض عن الأعمال والبيانات.
* **استعلامات متقدمة:** بحث شامل برقم الهوية الوطنية مع ربط ديناميكي للجداول (`JOIN`) لجلب بيانات الفئات الفعلية.
* **تكامل مستقر:** استخدام التخزين المحلي (`localStorage`) واستدعاءات الـ `Fetch API` لضمان سلاسة وسرعة عرض البيانات.

## 🚀 التشغيل السريع
1. تحديث إعدادات قاعدة البيانات في ملف `appsettings.json`.
2. تشغيل خادم الـ API عبر الـ Terminal باستخدام: `dotnet run`.
3. فتح واجهات المستخدم (HTML) لاستعراض النظام.
